# clawd-wander: Clawd が作業中にたまに、ふわっと消えて飾り付きで現れ直す

飾りを「現れたときに決めて、その作業のあいだずっと付けている」から、「作業中にたまに、Clawd 全体がふわっと消えて、飾りを付けた姿でふわっと現れ直し、
数秒したらまた消えて、飾りなしの姿で現れ直す」に変える。出入りのふわっと（浮き上がりながらドットが抜ける・降りながらドットが埋まる）は
.scratch/fade-in/spec.md の presence をそのまま使う。

**Status:** done（2026-10-11。テスト 169 件通過。実機での見え方はユーザーが「挙動は今のままでOK」と確認）
**Blocked by:** なし
**置き換えるもの:** .scratch/outfits/spec.md の R1（現れるときに選ぶ）・R2（現れてから消えるまで変えない）。
絵・位置・向き・寝姿・道具との重なりなど、それ以外の outfits の要件は引き続き守る。

## 経緯

2026-10-11 の最初の実装は、本体を動かさずに飾りの白だけを薄く出し入れしていた。実機で見たユーザーが
「飾りだけがふわっと出現/消失しているのですが、clawd 全体をふわっとさせて」と言ったため、Clawd 全体の出入りで入れ替える形に作り直した。

## 前提

- 1 コマ = 100 ms。入れ替えの消え方・現れ方は presence の FADE_FRAMES = 12 コマ（1.2 秒）。いる者が引っ込められるときの「ぴょんと跳ねる」は付けない（作業は続いているため）
- 入れ替えは同じ場所で起きる（消えるあいだも現れ直すときも x は変わらない。presence の現れかけ・消えかけは正面を向いて直立）
- タイミングはユーザーの指定が「たまに」だけなので次の値を仮定した（違えば定数を直す）。
  入れ替えを始める確率 OUTFIT_CHANCE = 1/450 /コマ（飾りなしで歩ける間の平均およそ 45 秒に 1 回）、現れ直してから付けておく長さ OUTFIT_HOLD = 80〜150 コマ（8〜15 秒）。
  1 回の入れ替え（消える 1.2 秒 + 現れ直す 1.2 秒 + 付けておく 8〜15 秒 + 戻りの消える・現れる 2.4 秒）はおよそ 13〜20 秒で、飾りが付いている時間は全体の 4 分の 1 ほど
- 消え始めと現れ直しの間は、本体は歩かず、道具・記号・紙吹雪は presence の見え方どおり隠れる（作業の状態は残る）。
  ただし押しつぶしは、presence の消えかけで捨てられる（squash の R5）ので、入れ替えの消えかけの 1.2 秒に会話の圧縮が始まると、その押しつぶしは捨てられる（R12 の例外。ユーザーが 2026-10-11 に「捨てる」を選んだ）
- 飾りの白は、本体といっしょに薄くなり、本体と同じだけ浮く。浮いた分、上端からはみ出す王冠などは切れる。浮いているとマスの組み合わせがずれ、
  薄い途中のコマでは空き・橙・白が 1 マスに入って形が崩れうるが、本体のドットが抜けている最中の 1.2 秒だけで、paint は多いほうの 1 色で塗る

## 要件

```text
R1  [WHEN]  本体が歩ける（いる・驚いていない・居眠りしていない・押しつぶされていない）うえに、ひとり遊びも行列もしておらず、飾りを付けておらず、入れ替え中でもない 1 コマに、
            帯は OUTFIT_CHANCE の確率で入れ替えを始める。本体は跳ねずに消え始める。消えきったあとに付ける飾り（王冠・サングラス・ヘッドフォン・小鳥から同じ確率）と、付けておく長さ（OUTFIT_HOLD）をこのとき決めておく。
R2  [WHEN]  入れ替え中の本体が消えきったとき、帯はその本体を同じ場所から、決めておいた飾りを付けて、現れかけにする（presence の現れ方）。
R3  [WHILE] 飾りを付けた本体が歩ける間、帯は付けておく残りコマを数える。尽きたら（ひとり遊び・行列をしていなければ）R1 と同じ消え方で消え始め、
            消えきったら同じ場所から、飾りなしで現れかけにする。
R4  [WHILE] 消えかけ・現れかけ（入れ替えのものも、作業の終わりに引っ込められたものも）の間、帯は本体を presence の見え方（正面・直立、濃さと浮き）で描き、飾りの白も本体と同じ濃さで間引き、同じだけ浮かせて描く。
R5  [WHEN]  入れ替え中の本体が引っ込められたとき（作業が終わったとき）、帯は入れ替えをやめ、本体をそのまま消えきらせる（現れ直させない）。
R6  [WHEN]  入れ替え中の消えかけの本体が「出す」と言われたとき、帯は反転させず、そのまま消えきってから現れ直させる（作業中は毎秒、出すと言われるため）。
R7  [WHERE] userConfig の outfits が false の構成では、帯は入れ替えを始めない（outfits の R3。飾りなしのまま）。
R8  [ALWAYS] 仲間（サブエージェント）は入れ替えない・飾りを付けない（outfits の R4）。
R9  [ALWAYS] 帯は、R1 の確率を引くコマ以外では乱数を呼ばない。R1 の確率を引くのは、R1 の条件を満たしたコマだけにする。
R10 [WHEN]  飾りを付けた本体が消えきったとき（作業が終わったとき）、帯は飾りを外す。次に作業が始まって現れるときは、飾りなしから始める。
R11 [KEEP][ALWAYS] 飾りの絵・位置・浮いている間の扱い（濃さ 1 の浮きでは白を描かない）・小鳥の側・寝姿・サングラスの寝姿・飾りなしの絵は、引き続き outfits の R5〜R12・R14・R15 のとおり。
R12 [KEEP][ALWAYS] 作業の開始・終了・仲間の出入り・跳ね・波乗り・蝶々・行列・紙吹雪・押しつぶしは、入れ替えで変わらない。ただし、入れ替えの消えかけ中に始まった押しつぶしは捨てられる（前提を参照）。
R13 [ALWAYS] 入れ替えの消えかけと、そのあとの現れかけの間も、居眠りまでの数え（idle）は進み続ける。作業の開始で現れるときは、0 から数え始める（emotes の R11 の「呼び出しが動いている間は数えない」は変えない）。
```

## 状態遷移表

本体の入れ替えの状態は「飾りなし」「入れ替え中（消えかけ）」「飾りあり」の 3 つに、presence の現れかけを加えた 4 つ。
入れ替え中は Member.outfitSwap が行き先（to と hold）を持つ。

| 現在 \ イベント | 始める（R1） | 毎コマ（本体がいる） | 消えきった | 引っ込められた |
| --- | --- | --- | --- | --- |
| 飾りなし | S1 → 入れ替え中（飾り X・長さ H を決める。消え始める） | S2 → 飾りなし | S3 → 飾りなし | S4 → 飾りなし |
| 入れ替え中（行き先 X か飾りなし） | S5 → 入れ替え中（起こらない） | S6 → 入れ替え中（消えかけが進む） | S7 → 飾りありなら X で、なければ飾りなしで、現れかけ（付けておく H） | S8 → 入れ替えをやめて、そのまま消える |
| 飾りあり（残り h） | S9 → 飾りあり（起こらない） | S10 → h > 1 なら 残り h − 1。h = 1 なら（遊び・行列でなければ）入れ替え中（行き先は飾りなし）、遊び・行列なら h = 1 のまま | S11 → 飾りなし（R10） | S12 → 飾りあり（そのまま消えかけ。消えきったら S11） |

## 契約

```text
契約: Member.outfit / wear / outfitSwap（crew.ts。outfit は Member.outfit を引き続き使う。wear・outfitSwap を足す）
- 値: outfit は OutfitId | null。wear は 0 以上の整数（outfit が null なら 0）。
      outfitSwap は null か { to: OutfitId | null, hold: 整数 }。to が OutfitId のとき hold は OUTFIT_HOLD の範囲、to が null（飾りなしへ戻る）のとき hold は 0
- 不変: 仲間は常に outfit = null・wear = 0・outfitSwap = null（R8）。outfitSwap があるのは、消えかけ（leaving）の本体だけ

契約: chooseOutfit(random)（outfits.ts。飾りなしを返さなくなる）
- 事前: random は 0 以上 1 未満を返す
- 事後: OutfitId。[0, 1) を 4 等分して crown・shades・headphones・bird
- 不変: random を 1 回だけ呼ぶ

契約: fadeOut(presence)（presence.ts）
- 事後: いる者なら { kind: 'leaving', left: FADE_FRAMES }（跳ねない）。それ以外はそのまま

契約: beginSwap(crew, random, timing)（crew.ts。旧名 dressUp）
- 事前: crew の先頭は本体
- 事後: R1 の条件を満たすときだけ、確率 OUTFIT_CHANCE で本体の presence を fadeOut にし、outfitSwap を { to: chooseOutfit の結果, hold } にする。それ以外は crew をそのまま返す
- 不変: 条件を満たさないコマでは random を呼ばない（R9）。引き当てたときは random を、飾り・長さの順に 2 回呼ぶ

契約: advance(crew, canvas, random, timing)（crew.ts。飾りの経過を足す）
- 事後: R2・R3・R10 のとおり、入れ替え中が消えきったら現れかけにし、付けておく残りを数え、消えきった本体の飾りを外す。入れ替えのために乱数を呼ばない

契約: setMain(crew, isWorking)（crew.ts。dress を持たない）
- 事後: 入れ替え中の本体に出すと言っても presence を変えない（R6）。引っ込めると outfitSwap を null にする（R5）。消えきるとき outfit を null・wear を 0 にする（R10）
```
