# colorful-body 開発メモ

## 開発コマンド

```bash
claude plugin validate colorful-body   # フックするイベントと呼ぶ機能を確かめる
claude plugin test colorful-body
npm run typecheck                      # リポジトリ直下で実行する
```

README の画像は [vhs](https://github.com/charmbracelet/vhs) で撮っている。撮影用の返答は `screenshots/sample.md`、撮り直す手順は `screenshots/before.tape` と `screenshots/after.tape` の冒頭にある。

## 仕組み

- フックするイベントは 1 つ: `ui.render`。対象は 2 つの描画で、応答の本文（`AssistantMessage`）と、あなたの発言（`UserMessage`）
- 本文は行ごとに分け、見出し・段落・リスト・表は自前の木で描き、それ以外は標準の `Markdown` 要素に渡す。発言は 1 つの枠の木で描く
- 使うエンジンの機能: `$.ui.resolve`（描画に使う要素の表）、`$.env.get`（環境変数 `HOME` だけ。`~` を絶対パスにするため）、`$.session.cwd`（作業ディレクトリ。相対パスを絶対パスにするため）
- 色は glow の dark スタイルに目で合わせた値（xterm-256 の 228・63・39・203・236 に近い色）。変えるときは `hooks/register.tsx` 冒頭の定数を書き換える

## 描き方の詳細

| 要素 | 標準 | colorful-body |
| --- | --- | --- |
| `#` 見出し | 太字・斜体・下線 | 黄文字・青紫背景のバッジ |
| `##` 以降の見出し | 太字 | 見出しの記号（`##`）を付けた青い太字 |
| インラインコード | 薄紫 | 赤字・灰背景（前後に空白を足す） |
| 箇条書き | `-` | `•`（入れ子はインデントで揃え、折り返した行も本文の位置に揃える） |
| 表 | 罫線の箱 | ヘッダの下に `─┼─`、列の間に `│`。全角文字は幅 2 で数え、狭いときは列を縮めてセル内で折り返す |
| 見出し・段落・リスト・表の境目 | そのまま | 空行を 1 つ入れる |
| 返答の先頭 | `●` | 自前で `●` を描き足す |
| あなたの発言 | `❯` 付きで、背景色が画面の幅いっぱいに付く | 右寄せの角の丸い枠（枠は青紫、背景は暗い紫）。幅は文章に合わせ、画面の 80% を超えたら折り返す |

## 標準の描画に任せるもの

作り直さずに、エンジン標準の描画のままにする。

- コードフェンス（` ``` `）
- 引用（`>`）
- リストの続きの行（インデントだけで始まる行）
- 要約として描かれる行（`isSummary`）
- あなた以外の発言（バックグラウンドタスクの通知、ほかのエージェントやセッションからのメッセージ）。枠で囲むのは、ターミナルで入力した発言（`origin.kind` が `composer`）だけ

## リンク（設定 `links`）

オンにすると、次をリンクにする。

- 本文の `https://…` や `http://…`（末尾の `.` `,` `)` などは含めない。全角文字の手前で止める）
- `[ラベル](https://…)` 形式（ラベルをリンクの文字にする）
- インラインコードの中身が URL のとき
- インラインコードの中身がパスらしいとき: `~/…`、`/a/b…`（2 階層以上）、`./…`、`../…`、拡張子のある `a/b.ts`。パスは `file://` に直し、`~` と相対パスは `HOME` と作業ディレクトリで絶対パスにする。末尾の `:行` や `:行:桁` は外してリンク先にする

`/compact` のようなスラッシュコマンドや、`a/b` のように拡張子のない相対パスはリンクにしない。コードフェンスの中と引用の中も対象外。

既定がオフなのは、Claude Code が端末の OSC 8 対応を検出できないと、リンクの文字のあとに URL を足して描くため。このとき URL が二重に出て、パスには長い `file://` が付く。環境変数 `FORCE_HYPERLINK=1` で OSC 8 を強制できるが、端末が実際に対応していないと意味がない。

## しないこと

- ツールの呼び出しや会話の内容を止めたり、書き換えたりしない（描画だけを差し替える）
- 通信しない。ファイルを読み書きしない。コマンドを実行しない
- 本文やパスを保存・送信しない。パスが実在するかは確かめない（リンクにするだけで、開かない）

## 既知の制限と未確認

- 表の幅は、全角と絵文字を幅 2、そのほかを幅 1 として数える。枠の幅も同じ。端末がこれと違う幅で描くと、罫線や右の枠が数桁ずれる
- パスの判定は文字の形だけで行う。拡張子のあるものは、存在しなくてもリンクになる
- `ctrl+o` で全文を出したときの枠は確かめていない
- ターミナル以外の画面（デスクトップなど）では確かめていない
- リンクは、herdr 越しでは OSC 8 が検出されず、代替表示（URL が二重に出る）になることを確かめた。`FORCE_HYPERLINK=1` でクリックが通るかは確かめていない
