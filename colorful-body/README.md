# colorful-body

Claude の応答本文を、Markdown ビューアの [glow](https://github.com/charmbracelet/glow) のような見た目で描く。
見出し・インラインコード・箇条書き・表に色が付き、どこが見出しでどこがコードかがひと目で分かる。

colorful-body:

![colorful-body の描画。# 見出しは黄文字・青紫背景のバッジ、## 見出しは ## 付きの青、インラインコードは赤字に灰背景、表は ─┼─ と │ で区切る](screenshots/after.png)

- ターミナルで確認（Claude Code 2.1.296）
- 描画だけを変える。会話の履歴に残る本文は書き換えない

## 描き方

| 要素 | 標準 | colorful-body |
| --- | --- | --- |
| `#` 見出し | 太字・斜体・下線 | 黄文字・青紫背景のバッジ |
| `##` 以降の見出し | 太字 | 見出しの記号（`##`）を付けた青い太字 |
| インラインコード | 薄紫 | 赤字・灰背景（前後に空白を足す） |
| 箇条書き | `-` | `•`（入れ子はインデントで揃え、折り返した行も本文の位置に揃える） |
| 表 | 罫線の箱 | ヘッダの下に `─┼─`、列の間に `│`。全角文字は幅 2 で数え、狭いときは列を縮めてセル内で折り返す |
| 見出し・段落・リスト・表の境目 | そのまま | 空行を 1 つ入れる |
| 返答の先頭 | `●` | 自前で `●` を描き足す |

色は glow の dark スタイルに目で合わせた値（xterm-256 の 228・63・39・203・236 に近い色）。変えるときは `hooks/register.tsx` 冒頭の定数を書き換える。

## 標準の描画に任せるもの

次は、作り直さずにエンジン標準の描画のままにする。

- コードフェンス（` ``` `）
- 引用（`>`）
- リストの続きの行（インデントだけで始まる行）
- 要約として描かれる行（`isSummary`）

## 設定

なし。

## この mod がすること・しないこと

すること:

- フックするイベントは 1 つ: `ui.render`（応答の本文 `AssistantMessage` の描画）。本文を行ごとに分け、見出し・段落・リスト・表は自前の木で描き、それ以外は標準の `Markdown` 要素に渡す
- 使うエンジンの機能: `$.ui.resolve`（描画に使う要素の表）

しないこと:

- ツールの呼び出しや会話の内容を止めたり、書き換えたりしない（描画だけを差し替える）
- 通信しない。ファイルを読み書きしない。コマンドを実行しない
- 本文を保存・送信しない

`claude plugin validate colorful-body` を実行すると、フックするイベントと呼ぶ機能を確かめられる。

## 既知の制限

- `#` 見出しのバッジは 1 行向け。長い見出しは、背景色つきで折り返して読みにくくなる
- 表の幅は、全角と絵文字を幅 2、そのほかを幅 1 として数える。端末がこれと違う幅で描くと、罫線が数桁ずれる
- 太字とインラインコードは、行の中で閉じているものだけを解釈する。行をまたぐものは文字のまま出る
- ターミナル以外の画面（デスクトップなど）では確かめていない

## 開発

```bash
claude plugin validate colorful-body
claude plugin test colorful-body
npm run typecheck   # リポジトリ直下で実行する
```
