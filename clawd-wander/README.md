# clawd-wander

Claude が作業している間、プロンプトの上で Clawd がうろうろする。
サブエージェントが動くと、種類も色も違う仲間（おばけ・ロボット・宇宙人・キノコ・恐竜・ネコ）が増える。

![サブエージェントを 3 体動かしている間、プロンプト上で Clawd と仲間がうろうろし、作業が終わると仲間が消えていく様子](screenshots/clawd-wander.gif)

- 作業が終わると跳ね、ツールが失敗すると驚き、手が止まると居眠りする
- 編集中はハンマー、調べ物中は虫めがね、新しく書くときは鉛筆、仲間を呼ぶときは旗、待ちを始めるときは砂時計、テスト中はフラスコを持つ
- ときどき飾り（王冠・サングラス・ヘッドフォン・小鳥）を付けた姿に変わる
- ときどき仲間が Clawd のあとを一列についていく。ひとりのときは、ひとり遊び（波乗り・蝶々を追いかける）をする
- テストが通ると紙吹雪が降り、`/compact` の間はぺしゃんこにつぶれる

ターミナルのみ（Claude Code 2.1.287 以降）。通信せず、ファイルの読み書きもしない。
プロンプト上の帯に描くほかの mod と一緒に使うと、その mod が表示している間はマスコットが隠れることがある。

## 設定

`/config` の clawd-wander の欄で変えられる。値を変えると、マスコットは出し直しになる。

| 項目 | 内容 | 既定 |
| --- | --- | --- |
| `doze_seconds` | ツールを使わない時間がこの秒数続くと居眠りする（1〜3600） | 60 |
| `prop_seconds` | ツールを使い終えてから道具を持ち続ける秒数（1〜3600） | 10 |
| `play` | Clawd がひとりのとき、ときどきひとり遊びをする（平均およそ 1 分に 1 回） | オン |
| `outfits` | ときどき飾りを付けた姿になる（平均およそ 45 秒に 1 回、8〜15 秒で元に戻る） | オン |

範囲外の秒数は既定値として扱う。
